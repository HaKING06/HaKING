# Security policy

Report security concerns privately to steam@haking.tr. Include the affected URL, reproduction steps and impact. Do not include passwords, API keys or another person's data. Avoid publishing exploit details before the issue is reviewed. Only the latest release is maintained. No response time or bounty is promised.

Steam API credentials belong in GitHub Actions secrets, never in client-side code. The site uses public Steam content and a mailto contact draft; it does not operate an email delivery backend or process payments.
